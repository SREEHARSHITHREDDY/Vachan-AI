WhatsApp chat import

In WhatsApp open a chat → ⋮ / contact name → Export chat → Without media, then choose the .txt file here. Only your own messages are read and stored — the other person's messages are ignored. Importing the same chat again never creates duplicates.

Gmail (sent mail)

Reads the emails you sent to find promises you made and detect when a later email fulfils one. Use a Google app password (Google Account → Security → 2-Step Verification → App passwords; myaccount.google.com/apppasswords), not your normal password. It is used for this sync only and is never stored. School/work accounts often disable app passwords — a personal Gmail works.
